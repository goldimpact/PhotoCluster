# 可选识别规则

“识别方式”选择“找同一画面的改图”（同源画面变体）后，可多选镜像版本、透视变化、轻度扭曲校正。基础旋转/倒置、缩放/拉伸及局部内容变化比较保留。动态媒体仍按关键帧比较，关闭规则不会排除图片、GIF 或视频本身。

默认勾选镜像与透视；扭曲校正标为高开销，默认关闭。关闭镜像会跳过额外的镜像描述子匹配（CPU 和 GPU 均适用）；关闭透视改用仿射估计；关闭扭曲则在基础对齐未通过时结束，不再执行局部形变估计与第二次画面校验。可选规则不会影响语义内容相似或近重复模式。

设置仅控制下一次“同步并分类”。复选框记忆在当前浏览器，扫描时锁定；分类结果显示实际使用的规则，避免将当前选项误当成已有结果的设置。标注的性能开销是相对提示，不保证固定倍数；即使关掉扩展项，同源几何验证仍有基础开销。

服务端验证规则名和布尔值，通过扫描线程传递到算法。结果缓存与正负候选对缓存都区分规则组合。全部规则开启时可复用旧版完整规则的已完成候选对；其他组合不会混用旧判定。改变规则无需强制重读手机原文件，增量分类即可。

所有六种识别方式、三个语义相似程度和三个主体门槛选项均有独立说明。扫描策略另有独立段落，切换增量/强制不会覆盖识别说明。模式、程度、规则的变化立即更新说明；刷新页面也会初始化正确文字。

验证包含 API 参数校验、线程传参、规则组合缓存隔离、关闭分支不执行、GPU 镜像开关、规则记忆和扫描锁定，以及全部说明文字的联动。未对这些开关作全库性能倍数承诺。

## 按目标理解模式

| 目标 | 当前方式 | 例子与边界 |
| --- | --- | --- |
| 找副本 | 快速 / 增强 / 宽松近重复 | 原图与压缩图；增强处理更多几何变化，宽松容忍更多细微差异 |
| 找同一画面的改图 | 同源画面变体 | 同一张表情包倒置、加字、裁剪；重新画出的同一角色通常不共享原画面 |
| 按画面内容归类 | 语义内容相似 | 不同来源的相近场景或画风；整图 CLIP 特征受背景和构图影响 |
| 自动发现主体 | 独立 DINOv2 整图与区域特征（实验） | 无需样例，自动提出角色或物体分组；跨画风身份准确率尚未验证 |
| 按事物类别整理 | 尚无独立类别系统 | 不同的猫都归为猫，与“同一只猫”是不同目标 |

“更宽 · 相近内容与画风”只是降低现有内容相似门槛，不启用角色身份识别。
界面提供可展开的例子与能力边界，内部模式标识和缓存规则不因文案更名改变。
独立的“自动发现主体”模式与 CLIP 内容模式使用不同模型，详见 [实现与验证边界](SUBJECT-GROUPING.md)。
