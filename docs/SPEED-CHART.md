# 速度图显示

切换语言前会将近期采样暂存到当前标签页的 sessionStorage。重载后先核对任务开始时间和
当前阶段，再把采样时间换算到新页面的时钟，继续绘图；新任务、新阶段或超过 60 秒的
快照不会混用。重载期间超过正常采样间隔时保留断线缺口，不虚构数据。无需重启服务。

运行中每 500ms 读取一次本地状态（请求不重叠），空闲时每 2 秒检查，隐藏页面不轮询。速度是近 2 秒已完成文件数量的差分，不是累计平均速度；每个文件耗时不同，不等同于网络的逐字节带宽。

几何及语义匹配每完成一个媒体更新计数（包括完全相同文件），同源特征准备每完成一个有序结果也上报，不再凑满 25 个才上报。单个文件尚未完成时不会虚构进度。

绘图由 requestAnimationFrame 驱动，跟随浏览器刷新节奏；用半秒显示延迟在已收到的采样点之间插值，让横轴连续滚动。不推算尚未收到的速度，不在断线缺口补线。暂停、隐藏页面、连接失败或超过 3 秒无采样时停止动画。支持系统减少动态效果设置。

纵轴刻度是 SVG 外的普通 HTML 文本，字号不随图形拉伸。SVG viewBox 宽度跟随容器宽度，圆点也保持比例。移除无明确用途的滑块，使用悬停/触摸查看采样，键盘焦点在图表时可用左右键、Home、End 查看。

自动测试覆盖差分计速、阶段切换、断线缺口、两次网络响应之间的动画、没有新数据时不外推、隐藏/暂停/减少动画，以及每文件进度上报。本环境没有可用 Browser 连接，未完成真实浏览器视觉验收。
