# PhotoCluster

[English](README.md) | **简体中文**

在电脑上通过 ADB 扫描安卓手机的**图片、GIF 和视频**，把重复或相似内容展示为
虚拟文件夹。查看、对比后，可直接删除手机上的所选原文件，或移动到手机真实目录。
媒体分析与界面翻译全部在本地进行。

**当前重点是 Windows / Linux 操作 Android。macOS 和 iOS 等具备设备后再推进，iOS 尚未实现。**
Linux 与 WSL 的启动、连接方式及验证边界见 [Linux / WSL 指南](docs/LINUX.md)。

## 虚拟文件夹是什么

手机上的 `a/1.jpg` 和 `b/2.gif` 可以归入同一个界面分组，原文件仍在各自目录。
分类不会在手机上建立分类目录。删除只针对所选文件对应的手机原路径；移动只能选择
已发现、仍存在的真实相册目录。虚拟文件夹不支持新增、导入文件。

- **同源画面变体**：旋转、镜像、缩放、拉伸、加字等局部变化；可选透视及轻度扭曲校正。
  扭曲校正开销较大，默认关闭。
- **语义内容相似**：可选的本地 CLIP 模型比较图片、动画和视频关键帧，可跨格式归组。
  比较的是整幅画面，尚不能可靠聚齐同一角色的二创、重绘和表情包；放宽阈值也可能混入不同主体。
- **快速 / 增强 / 宽松近重复**：用于更接近副本的比较。
- **自动发现主体（实验）**：独立的本地 DINOv2 模型比较整图与局部区域，无需选择样例，
  自动提出角色或物体分组，支持图片、GIF 与视频抽样帧。跨画风二创的身份准确率尚未验证。
  选择此模式后可点击「安装 / 检查主体模型」下载约 24 MB 公共模型；分类时不联网推理。
- 扫描区域内的 **本地缓存 · 占用、用途与清理** 显示占用，可预览并确认清理分组、分析缓存
  或完整媒体库缓存。手机原文件、已安装模型、设置和操作日志保留。模型或特征版本变化会
  使对应特征与分组失效，但兼容的预览仍可复用，不必清空一切。
- 未归组文件夹、损坏媒体待检查卡片、按需原图、首尾循环浏览、鼠标位置缩放、并排对比。
- 分组及组内日期排序、搜索、页码跳转、增量缓存、实时进度与速度曲线。
- 顶部 **语言 / Language** 可切换中文和英文并记忆选择。切换会重新加载页面，保留扫描
  设置、相册选择与筛选，后台分类继续运行；预览窗口会关闭，文件操作需重新勾选。
  切换语言不会使照片特征或分类缓存失效。近期速度采样也会保存，重载后继续显示同一
  任务、同一阶段的曲线；较长的采样间隔保留断点，不补造速度。

识别属于启发式算法。严重变形、低纹理、抽帧间隔内的短暂画面或候选检索限制仍可能漏检。
相似分数不是重复概率，也不会触发自动删除。

## 启动（Windows）

### 普通用户：控制窗口

准备好下述 Python、ADB、FFmpeg 后，双击根目录 **PhotoCluster.cmd**。
控制窗口提供「启动并打开」「打开界面」「退出程序」、依赖安装 / 修复、日志及语言切换。
首次启动会安装 Python 依赖；以后使用已有环境，不会每次启动都下载依赖。
显示“正在运行”后才打开浏览器，退出后显示“尚未启动”。
启动器会记住语言，并在打开网页时使用该语言。日志窗口每半秒追加新内容，提供横纵
滚动条、自动跟随和“回到最新”；翻阅历史时不会被新日志拉回底部。

网页顶部也有运行状态和「退出 PhotoCluster」。**关闭标签页不会退出后台服务**，
这是为了避免误关页面中断分类。点击退出并确认后，会停止分类、保存已完成缓存，
等待已有删除 / 移动 / 读取结束，再关闭服务。没有“强杀”按钮。网页断线会说明是否
曾收到退出确认，不会把普通网络失败当成成功退出。

如果检测到旧服务，在控制窗口点击「切换到新版」并确认即可尝试自动迁移，不需要寻找
原终端。先结束分类、关闭预览，并在切换期间暂停其他页面操作。程序只对核实为本项目、
同一用户且空闲的旧服务发送正常退出请求；不会强杀或修改照片。无法安全自动迁移时，
会给出不需要命令行的系统重启步骤；不会强行接管其他软件。

### 命令行用户

安装 **Python 3.11+**、[ADB / Platform Tools](https://developer.android.com/tools/releases/platform-tools)
和 [FFmpeg + FFprobe](https://ffmpeg.org/download.html)，并将可执行文件加入 `PATH`。
手机开启 USB 调试，通过 USB 连接并授权电脑；用 `adb devices` 检查连接。

```powershell
git clone https://github.com/goldimpact/PhotoCluster.git
cd PhotoCluster
.\start.ps1
# 已有依赖，不安装且不自动打开浏览器：
.\start.ps1 -NoInstall -NoBrowser
```

打开 **http://127.0.0.1:8765**。点击「同步目录」读取相册，点击「同步并分类」开始。
默认扫描全部相册、跨相册比较、同源画面变体、增量更新；镜像与透视默认开启，扭曲默认关闭。

脚本建立 `.venv` 并安装 Python 依赖。语义模型与 GPU 依赖按需安装：

```powershell
.\start.ps1 -InstallModel
.\start.ps1 -InstallGpu
# 需要本地代理时，仅用于下载依赖 / 模型：
.\start.ps1 -InstallModel -Proxy http://127.0.0.1:7897
# 强制使用 CPU：
.\start.ps1 -Accelerator cpu
```

模型约 89 MB。不安装模型仍可使用同源和近重复模式；选择语义模式时会提示安装方法。
GPU 需要兼容的 NVIDIA 驱动及 CUDA 12 运行库；不可用时回退 CPU。目前 CLIP 推理使用
CPU INT8，GPU 用于部分检索和特征匹配，不能保证每个阶段都使用显卡。

已有依赖时，可直接启动，跳过安装检查：

```powershell
.\start.ps1 -NoInstall
```

Linux 安装 Python 3.11+、ADB、FFmpeg 后，运行 `bash start.sh --check` 完成安装检查，
再用 `bash start.sh --no-install` 启动。Linux 使用独立的 `.venv-linux` 环境；WSL 默认
缓存位于 `data/wsl/`，可复用 Windows 已连接的 `adb.exe`。Windows 已占用 8765 端口时，
WSL 加上 `--port 8766`。Ubuntu 22.04 的 Python 升级、USB 权限与代理差异详见指南。
Linux 图形桌面（或配置了 WSLg 的 WSL）也可运行 `bash PhotoCluster.sh` 打开控制窗口，
需要当前 Python 带有 Tk。没有图形环境时用 `bash start.sh`，网页仍能退出服务。
`requirements-lock.txt` 是实测 Windows Python 3.11
CPU 依赖快照，GPU 依赖单独列出。日常使用不需要 Node/npm。

## 同步与文件操作

| 功能 | 行为 |
| --- | --- |
| 同步目录 | 更新 Android 媒体库清单、移除失效结果引用；不计算相似度 |
| 增量更新 | 先同步，处理新增 / 变化文件，复用兼容特征和比较结果 |
| 强制全量重算 | 重新读取所选原文件、提取特征和分类，不复用旧比较缓存 |
| 删除 / 移动 | 展示准确路径，用户确认，重新校验文件内容，再操作所选原文件 |

程序不会持续监控手机。扫描使用开始时的目录快照，期间新增文件在下一轮同步纳入。
只有整轮分类完成才发布新分组；扫描中或停止 / 失败后，会明确提示下方可能是上次结果。

删除是**永久删除，不进回收站**，重要媒体应另有备份。同名目标不会被覆盖。成功操作会
更新当前结果里该文件的所有引用；仅剩一个成员的组转入「未归组媒体」。程序会通知
Android 媒体库，但手机相册界面可能延迟刷新。批量操作在断连时可能部分成功，需核对
各文件结果；也无法阻止其他手机应用在哈希校验与实际操作之间修改文件。

覆盖范围是 Android MediaStore 中可读取的本地图片和视频，不包含云端文件、应用私有
数据、未索引或 `.nomedia` 隐藏内容。媒体库未收录的空目录不提供为移动目标。

## 隐私与缓存

不使用在线识别、在线翻译、照片上传或第三方界面 CDN。服务仅监听本机，保留 Host / Origin
检查，不应作为公网或局域网共享服务部署。依赖安装与显式模型下载会连接公开软件源；
分类、解码和推理都在本机进行。

**`data/` 全部视为私人数据**：包括设备标识、手机路径、缩略图、恢复帧、特征向量、模型、
分组、错误信息和操作日志。日志及导出的 CSV / JSON 也可能含隐私，不要提交或贴入公开
issue。浏览器记忆语言、规则，并在切换语言时临时保存视图设置。

图片 / GIF 原图按需读取到内存，单张查看上限 150 MB，切图或关闭释放 Blob 引用。
视频及损坏文件恢复会使用临时文件；视频租约关闭或空闲超时后清理。强杀进程可能留下
临时文件，内存释放也不是安全擦除。完全无法解码的媒体仍显示占位卡片与原因。

## 开发与规划

```text
python -m pip install -r requirements.txt
npm ci
python -m pytest -q
npm test
```

测试使用合成媒体与模拟手机操作；CUDA、真实模型、FFmpeg 缺失时，相应测试跳过。
CI 在 Windows / Ubuntu 运行 CPU 测试。VM / jsdom 是界面逻辑测试，不代表真实浏览器
视觉验收或 iOS 设备支持。

[AGENTS.md](AGENTS.md) 是供支持该约定的 AI 编程工具读取的项目开发规则，规定隐私、
文件操作安全、缓存兼容、中英文维护和测试方式。它不是 skill；`SKILL.md` 是另一个
用于封装可复用工作流程的机制，本项目无需为了这些规则专门创建 skill。

更多实现说明见 [架构](docs/ARCHITECTURE.md)、[识别规则](docs/CLASSIFICATION-RULES.md)
与 [速度图](docs/SPEED-CHART.md)。只读性能脚本需要使用者自己的扫描缓存，输出保留在
`data/`；旧的个人实验报告及私有基线快照不随公开仓库发布。

近期先完善 Windows / Linux 的 Android 使用流程与验证。具备硬件后，再推进 macOS、
iOS 设备发现、系统许可范围内的媒体读取及管理能力，并进行真机验证；更多
桌面 / 设备兼容性与真实浏览器验证；可复现的识别与性能评估。iOS 不会直接套用 Android
的任意文件路径操作假设。
